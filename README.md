# 인사·총무 실습앱

> ⚠️ **교육용 가상 자료 프로젝트**
> 여기 나오는 회사·직원·자산·급여는 전부 학습을 위해 지어낸 허구입니다.
> 실존 인물·기업과 무관하며, 실제 인사·급여·회계 업무에 사용할 수 없습니다.

신입 인사·총무 담당자가 **실제 회사 시스템을 건드리지 않고**
근태·휴가 결재와 비품 불출·반납을 연습하는 단일 HTML 앱입니다.
실수해도 안전하고, [처음 상태로 초기화] 한 번이면 원래대로 돌아갑니다.

## 무엇이 들어 있나

| 화면 | 하는 일 |
| --- | --- |
| 대시보드 | 오늘의 결재 대기·이상 근태·반납 지연을 한눈에 |
| 근태 현황 | 지각·조퇴·결근 직원만 걸러 보기 |
| 휴가 관리 | 휴가 승인/반려(사유 필수), 신규 신청, 잔여 연차 초과 경고 |
| 비품 대장 | 재고 부족 비품 찾기 |
| 불출·반납 | 비품 불출 등록, 반납 지연 건 처리 |

왼쪽 아래 **실습 미션 8개**가 자동으로 채점됩니다.

## 실행

파일 하나로 끝납니다. 설치할 것도, 서버도 필요 없습니다.

```
index.html 을 브라우저로 열기 (더블클릭)
```

작업 내용은 브라우저 안(localStorage)에만 저장됩니다.
서버로 나가는 통신이 **한 건도 없습니다.**

## 배포 (Vercel)

1. 이 저장소를 Vercel 에서 **Import**
2. Framework Preset 은 `Other`, 나머지는 건드리지 않고 **Deploy**

빌드 과정이 없는 정적 사이트라 `vercel.json` 설정대로 바로 뜹니다.
문서·스크린샷은 `.vercelignore` 로 배포에서 빼 두었습니다.
