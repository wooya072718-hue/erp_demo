# 인사·총무 실습앱

> ⚠️ **교육용 가상 자료 프로젝트**
> 여기 나오는 회사·직원·자산·급여는 전부 학습을 위해 지어낸 허구입니다.
> 실존 인물·기업과 무관하며, 실제 인사·급여·회계 업무에 사용할 수 없습니다.

신입 인사·총무 담당자가 **실제 회사 시스템을 건드리지 않고**
근태·휴가 결재와 비품 불출·반납을 연습하는 단일 HTML 앱입니다.
실수해도 안전하고, [처음 상태로 초기화] 한 번이면 원래대로 돌아갑니다.

## 무엇이 들어 있나

| 화면 | 하는 일 |
| --- | --- |
| 대시보드 | 오늘의 결재 대기·이상 근태·반납 지연을 한눈에 |
| 근태 현황 | 지각·조퇴·결근 직원만 걸러 보기 |
| 휴가 관리 | 휴가 승인/반려(사유 필수), 신규 신청, 잔여 연차 초과 경고 |
| 비품 대장 | 재고 부족 비품 찾기 |
| 불출·반납 | 비품 불출 등록, 반납 지연 건 처리 |

왼쪽 아래 **실습 미션 8개**가 자동으로 채점됩니다.

## 실행

파일 하나로 끝납니다. 설치할 것도, 서버도 필요 없습니다.

```
index.html 을 브라우저로 열기 (더블클릭)
```

작업 내용은 브라우저 안(localStorage)에만 저장됩니다.
실습 기능만 쓴다면 서버로 나가는 통신이 **한 건도 없습니다.**
(대시보드 맨 아래 [연결 테스트] 버튼만 예외 — 아래 참고)

## AI 연결 확인 (개발 확인용)

대시보드 맨 아래에 **[연결 테스트]** 버튼이 있습니다.
Gemini API 키가 제대로 연결됐는지만 확인하는 버튼이고, 실습 기능이 아닙니다.

누르면 서버가 두 가지를 확인합니다.

| 순서 | 확인하는 것 |
| --- | --- |
| 1 | 키가 유효한가 — 모델 목록을 받아온다 (요금 안 듦) |
| 2 | 실제로 답이 오는가 — 짧은 질문을 한 번 던진다 |

**API 키는 브라우저로 내려오지 않습니다.** 키를 HTML 에 넣으면 페이지를 연
누구나 볼 수 있으므로, 키는 서버(`api/gemini-test.js`)의 환경변수에만 둡니다.

모델은 `gemini-3.7-flash` → `3.6` → `3.5` 순으로 시도합니다.
한 모델이 과부하(503)면 자동으로 다음 것으로 넘어갑니다.

> ⚠️ 이 버튼은 **서버가 있어야** 동작합니다.
> `index.html` 을 더블클릭해서 연 경우에는 "서버에 닿지 못했습니다" 가 뜹니다.
> 나머지 실습 화면 5개는 그래도 정상 동작합니다.

## 배포 (Vercel)

1. 이 저장소를 Vercel 에서 **Import**
2. Framework Preset 은 `Other`, 나머지는 건드리지 않고 **Deploy**
3. 배포 후 **Settings → Environment Variables** 에서 아래를 추가하고 재배포

   | Name | Value |
   | --- | --- |
   | `GEMINI_API_KEY` | 구글 AI Studio 에서 받은 키 |

3번을 건너뛰면 실습 화면 5개는 잘 뜨지만 [연결 테스트] 만 실패합니다.
키는 https://aistudio.google.com/apikey 에서 무료로 받습니다.

빌드 과정이 없는 정적 사이트라 `vercel.json` 설정대로 바로 뜨고,
`api/` 폴더는 Vercel 이 알아서 서버 함수로 돌려 줍니다.
문서·스크린샷은 `.vercelignore` 로 배포에서 빼 두었습니다.

### 내 컴퓨터에서 AI 버튼까지 시험해 보려면

```
npm i -g vercel
vercel dev
```

`vercel dev` 는 같은 폴더의 `.env` 에서 `GEMINI_API_KEY` 를 읽습니다.
